# Historische AC08-Testreferenzen

Die SVGs unter `svgs/` stammen aus dem früheren Verzeichnis
`src/artifacts/converted_images/converted_svgs/`.
Sie bleiben bytegleich erhalten, weil die Regressionsbatterie und die
Qualitätsprüfung darauf zurückgreifen. Es handelt sich um Testreferenzen,
nicht um Eingaben der regulären `semantic-only`-Konvertierung.

Neue Konvertierungsausgaben gehören nach `artifacts/converted_images/`
oder in einen ausdrücklich gewählten lokalen Ausgabeordner.
