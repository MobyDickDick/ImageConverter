# Helle Kreisränder bei gemischter Überdeckung

`summary.json` erhält Seeds, Eingabe-/Ausgabehashes, unabhängige Messungen und
die serielle Gegenprobe sowie beide Hypothesen. `checks.json` enthält Tests.
Der Runner `tools.run_seeded_scene_check evaluate_mixed_overlap` erzeugt und
entfernt die Arbeitsdaten. Befehle und Grenzen stehen im
[Arbeitspaket](../../../docs/next_arbeitspaket_2026-10-24_circle_rims.md).
