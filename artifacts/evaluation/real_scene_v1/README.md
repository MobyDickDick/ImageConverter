# Reale Szenen und benannte Referenzen

Die kompakte Zusammenfassung dokumentiert echte CLI-Läufe und unabhängige
Objekt-/Regionsprüfungen, einschließlich der negativen realen Ergebnisse.
Reale Annotationen stehen in `config/real_scene_families.json`.

Vollständige Rohdaten liegen lokal unter `.tmp/real05/`; CI lädt eigene
Raster, Ausgaben und Workerberichte hoch. Ein frischer Checkout muss die
finalen Prüfungen neu ausführen. Historische Vorher-Läufe erfordern die
damalige Runtime. Die Zusammenfassung ersetzt keine unabhängige Prüfung.
