# Abgewiesene adaptive Identitätskontrolle

24 tatsächliche Versuche mit fünf Sekunden Budget und adaptiven Zeitscheiben.
Die Renderer-Zugänge und der Verzögerungsarm bestehen jeweils die unabhängigen
Gates; die verlangte SVG-Identität besteht jedoch nicht. Veränderte Renderzeiten
beeinflussen die adaptive Modellreihenfolge. Bericht, Raster, SVGs und Rohereignisse
bleiben als negativer Kontrollbefund erhalten. Diese Versuche zählen nicht zur
bestandenen Kontrollabnahme unter `../component_value_v1`.
