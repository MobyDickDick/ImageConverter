# Gleichfarbige Überdeckungsinstanzen: kompakte Evidenz

`summary.json` enthält Seed, Eingabe-/Referenz-/Ausgabehashes, unveränderte
Grenzen, Messwerte, native Entscheidungen und Suchtelemetrie für alle Fälle:
0/12 vorher, 12/12 nachher, weiterer Seed 12/12 und gekoppelte Varianten 16/17.
`checks.json` dokumentiert Prüfkommandos und Exit-Codes. Die Rohdaten bleiben
unter `.tmp/same-paint-*`; ihre dauerhafte Verfügbarkeit wird nicht behauptet.

Reproduktion, Ursachen und Grenzen stehen im
[Arbeitspaket](../../../docs/next_arbeitspaket_2026-10-24_same_paint.md).
Dies ist synthetische Entwicklung; die unabhängige reale Gesamt-Abnahme bleibt offen.
