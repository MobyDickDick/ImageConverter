# BENCHMARK-PRACTICAL-01: Vorbereitung

`summary.json` dokumentiert 20 **bekannte Entwicklungskandidaten** und zwei echte
Converter-Piloten mit erneut geprüften SVGs. Die 20 Topologien sind vorläufig,
ohne unabhängige Annotation; neue gesperrte Familien, externe Vergleichsläufe
und menschliche Zeitmessungen fehlen. `study_complete=false`.

Die beiden Pixelprüfungen bestehen; eine vollständige fachliche Abnahme wird
nicht behauptet. Es gibt keinen Nachweis einer Zeitersparnis oder eines
Vorteils gegenüber anderen Verfahren.

Eingaben, Befehle, SVGs und vollständige Berichte liegen lokal unter
`.tmp/practical01/`. Prüfsummen binden diese Zusammenfassung an die Rohdaten;
sie ersetzen deren erneute Prüfung nicht. Für einen frischen Checkout gelten
die Befehle in der [Paketdokumentation](../../../docs/history/next_arbeitspaket_2026-10-21_practical_benchmark.md).
Messzeiten und Rohdatenprüfsummen können sich bei einem neuen Lauf ändern.
