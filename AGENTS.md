# Arbeitsregeln

- Jede neue Aufgabe erhält einen eigenen Branch (standardmässig `codex/…`).
- Tests, Testkonvertierungen und Benchmarks ausschliesslich auf GitHub Actions
  ausführen. Keine lokalen Testläufe starten.
- Änderungen mit einem Pull Request und nachprüfbaren CI-Ergebnissen bereitstellen.
  Fehlgeschlagene oder noch ausstehende Prüfungen ausdrücklich nennen.
